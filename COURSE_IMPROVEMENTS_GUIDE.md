## Дополнительные Темы для Добавления

### 1. EXPLAIN и Query Optimization (КРИТИЧНО!)
```sql
-- Смотрим план выполнения
EXPLAIN SELECT * FROM users WHERE email = 'test@example.com';

-- Выполняем и видим фактические значения
EXPLAIN ANALYZE SELECT * FROM users WHERE email = 'test@example.com';
```

**Что ищут:**
- Sequential Scan (медленно) vs Index Scan (быстро)
- Actual rows vs Estimated rows (большие отличия = проблема)

### 2. CROSS JOIN
```sql
SELECT * FROM table_a 
CROSS JOIN table_b;
-- Результат: каждая строка из A соединена с каждой строкой из B
```

### 3. DISTINCT ON (PostgreSQL специфичное)
```sql
-- Получить первый заказ каждого клиента
SELECT DISTINCT ON (customer_id) customer_id, order_date, total
FROM orders
ORDER BY customer_id, order_date DESC;
```

### 4. Recursive CTE
```sql
-- Получить иерархию подразделений
WITH RECURSIVE departments_tree AS (
    SELECT id, name, parent_id, 0 AS level
    FROM departments
    WHERE parent_id IS NULL
    
    UNION ALL
    
    SELECT d.id, d.name, d.parent_id, dt.level + 1
    FROM departments d
    JOIN departments_tree dt ON d.parent_id = dt.id
)
SELECT * FROM departments_tree;
```

### 5. Window Functions - Advanced
```sql
-- Процент от общего объема
SELECT 
    product,
    sales,
    SUM(sales) OVER () AS total_sales,
    ROUND(100.0 * sales / SUM(sales) OVER (), 2) AS percent
FROM sales_data;

-- Скользящее среднее за 3 периода
SELECT 
    date,
    sales,
    AVG(sales) OVER (ORDER BY date ROWS BETWEEN 2 PRECEDING AND CURRENT ROW) AS moving_avg_3
FROM sales;
```

### 6. Parameterized Queries (безопасность!)
```python
# Правильно
query = "SELECT * FROM users WHERE email = %s AND age > %s"
cursor.execute(query, ('test@example.com', 25))

# НЕПРАВИЛЬНО (SQL Injection!)
query = f"SELECT * FROM users WHERE email = '{email}' AND age > {age}"
```

### 7. Common SQL Mistakes (типичные ошибки)
- ❌ WHERE col = NULL (должно быть IS NULL)
- ❌ SELECT * в production
- ❌ Забыли ORDER BY перед LIMIT
- ❌ Забыли WHERE в UPDATE/DELETE
- ❌ Использовали DISTINCT вместо GROUP BY
