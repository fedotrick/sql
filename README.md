## ❓ Часто Задаваемые Вопросы

### Q: Нужен ли интернет для работы?
**A:** Только для первого открытия страницы. После этого курс работает полностью офлайн.

### Q: Где сохраняются мои данные?
**A:** В localStorage браузера (локально на вашем компьютере).

### Q: Могу ли я перенести прогресс на другой компьютер?
**A:** К сожалению, нет встроенной функции синхронизации. Но вы можете экспортировать/скачать прогресс.

### Q: Что если я потеряю прогресс?
**A:** После завершения курса скачайте сертификат! Также не очищайте историю браузера.

### Q: Есть ли упражнения для практики?
**A:** Это теоретический курс с примерами. Для практики используйте PostgreSQL, SQLite или другие СУБД.

### Q: Как скачать курс?
**A:** Это просто набор файлов - скопируйте всю папку проекта на другой компьютер!
