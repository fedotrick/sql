# 🚀 Интерактивный Курс SQL - Описание Функций

## Архитектура

```
┌─────────────────────────────────────────────────────┐
│           SQL Academy Interface (HTML5)              │
├──────────────────┬──────────────────┬───────────────┤
│   Sidebar        │  Main Content    │  Right Panel  │
│  Navigation      │  Chapter View    │  Bookmarks    │
│  Progress        │  Markdown        │  Statistics   │
│  Search          │  Code Highlight  │  Completion   │
└──────────────────┼──────────────────┼───────────────┘
         ↓                  ↓                  ↓
┌─────────────────────────────────────────────────────┐
│         CourseApp Class (course.js)                 │

│  - Progress Tracking                               │

│  - Event Handling                                  │
│  - Theme Management                               │
└─────────────────────────────────────────────────────┘
         ↓                  ↓                  ↓
    Chapters         User State        Browser APIs
```

## Основные компоненты

### 1. **Левая сайдбар (Навигация)**
- **Logo & Progress Circle**: Визуальное представление прогресса
- **Search Input**: Поиск по названиям глав (в реальном времени)
- **Course Navigation**: 
  - Список всех глав сгруппированных по разделам
  - Визуальные индикаторы (галочка ✓ для завершенных)
  - Звезды (★) для закладок
  - Активное выделение текущей главы
  - Гладкая прокрутка при выборе

### 2. **Основной контент (Center)**
- **Заголовок**: Навигационная строка с хлебными крошками
- **Контент главы**: 
  - Markdown парсер в реальном времени
  - Поддержка: заголовки, списки, код, таблицы, ссылки
  - Подсветка синтаксиса SQL через Highlight.js
  - Адаптивная типография
- **Навигация**: Кнопки "Предыдущая" / "Следующая"
- **Действия**: 
  - Отметить как пройденное
  - Добавить в закладки

### 3. **Правая панель (Статистика)**
- **Закладки**: 
  - Список сохраненных глав
  - Быстрый переход
  - Удаление закладок
- **Статистика**:
  - Всего глав / Пройдено
  - Время учебы
  - Серия дней
  - Прогресс по разделам

## 📊 Система отслеживания прогресса

### LocalStorage структура
```javascript
{
  currentChapterIndex: 0,           // Текущая глава
  completedChapters: [1, 2, 5],     // Завершенные главы
  bookmarkedChapters: [3, 7],       // Закладки
  studentName: "Иван Петров",       // Имя студента
  studyTimeSeconds: 3600,           // Время учебы в сек
  streakDays: 5,                    // Серия дней обучения
  lastStudyDate: "2024-01-15"       // Последний день учебы
}
```

### Возможности сохранения
- ✅ Автоматическое сохранение каждые 5 минут
- ✅ Сохранение при:
  - Отметке главы как завершенной
  - Добавлении/удалении закладок
  - Переходе между главами
  - Смене темы
- ⚠️ Данные хранятся только в браузере
- 🔄 Легко сбросить (кнопка "Сбросить прогресс")

## 🎨 Темы оформления

- Белый фон
- Темный текст
- Синий акцент (primary)
- Хорошо для дневного времени

- Темно-синий фон (#0f172a)

- Кровавая синь акцент
- Хорошо для ночного времени

### Переключение
- Кнопка в верхнем右
- Сохраняется в localStorage
- Применяется при загрузке

## 🔐 Безопасность

### Что защищено
- ✅ Санитизация HTML (escapeHtml функция)
- ✅ Экранирование кода перед отображением
- ✅ Отсутствие eval() функций

### Что НЕ защищено
- ⚠️ Код не загружается с сервера (локально)
- ⚠️ Нет аутентификации
- ⚠️ Данные не зашифрованы в localStorage
- ⚠️ Не защищено от XSS в пользовательском вводе

### Рекомендации
- Используйте в приватном браузере
- Не вводите чувствительные данные
- Регулярно очищайте кэш
- Используйте HTTPS если развертываете на сервере

- 📦 Lazy loading контента

## 🔗 Интеграция


   ```javascript

   generateCertificate(

       certificateId

   ```

## 🚀 Развертывание

### Самый простой способ
```bash
# Python
python -m http.server 8000

# Затем открыть http://localhost:8000
```

### На GitHub Pages
```bash
git push origin gh-pages
# Доступно на: username.github.io/repo-name
```

### На собственном сервере
```bash
# Скопировать все файлы на сервер
scp -r ./* user@server:/var/www/sql-course/

# Настроить HTTPS и веб-сервер (Nginx/Apache)
```

### Docker контейнер
```dockerfile
FROM nginx:alpine
COPY . /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```
