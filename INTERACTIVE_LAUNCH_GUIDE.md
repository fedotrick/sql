# 🚀 SQL Academy - Интерактивный курс | Руководство по запуску

## Что это?

**SQL Academy** - это полностью функциональный интерактивный HTML-курс, основанный на исходном markdown контенте. Включает:

- ✅ 94 интерактивные главы
- ✅ Отслеживание прогресса с сохранением
- ✅ Темный/светлый режим
- ✅ Система закладок
- ✅ Поиск по главам
- ✅ Статистика обучения
- ✅ Полностью адаптивный дизайн

---

## ⚡ Запуск за 30 секунд

### Вариант 1: Просто откройте (Самый простой)

```bash
# Windows
start index.html

# Mac
open index.html

# Linux
xdg-open index.html
```

### Вариант 2: Python сервер (Рекомендуется)

```bash

```

### Вариант 3: Node.js сервер

```bash

# Откройте в браузере
```

## 💾 Ваш прогресс сохраняется автоматически!

### Как это работает?
- Все данные хранятся в браузере (localStorage)
- Автосохранение каждые 5 минут
- Сохранение при каждом действии
- Данные НЕ теряются при перезагрузке страницы

### Что сохраняется?
- ✓ Текущая глава
- ✓ Завершенные главы
- ✓ Закладки
- ✓ Время обучения
- ✓ Серия дней обучения
- ✓ Ваше имя (для сертификата)

### Сброс
- Кнопка "🔄 Сбросить" в левой панели
- Требует подтверждение
- Удалит все прогресс и статистику

## ❓ Часто задаваемые вопросы

### Q: Прогресс исчез!
**A:** Вероятно, очищен кэш браузера. К сожалению, данные локальные. Используйте настройки браузера, чтобы исключить этот сайт из очистки.

### Q: Где хранятся данные?
**A:** В localStorage браузера. DevTools (F12) → Storage → Local Storage → courseProgress

### Q: Можно ли синхронизировать между устройствами?
**A:** Пока нет. Это клиентское приложение. В будущем планируется облачная синхронизация.

### Q: Есть ли упражнения для практики?
**A:** Это теоретический курс с примерами. Практикуйте в PostgreSQL отдельно.

### Q: Можно ли скачать курс?
**A:** Да! Вся папка содержит все файлы. Копируйте на любой компьютер.

### Q: Что если найду ошибку?
**A:** Спасибо! Проверьте исходные markdown файлы или создайте Issue на GitHub.

### Q: Работает без интернета?
**A:** Да! Код с CDN (Highlight.js) может потребовать интернет. Без него - просто без подсветки синтаксиса.

### Q: Какие браузеры поддерживаются?
**A:** Chrome 90+, Firefox 88+, Safari 14+, Edge 90+. IE 11 не поддерживается.
