### 3. course.js (20 KB) - **APPLICATION LOGIC**

**Purpose**: Core functionality - state management, navigation, events

**Main Class**: `CourseApp`
- Manages chapter navigation
- Handles progress tracking
- Manages localStorage persistence
- Controls theme switching
- Implements keyboard shortcuts
- Parses markdown to HTML

**Key Methods**:
- `loadChapter(index)` - Load specific chapter
- `toggleChapterComplete()` - Mark as done
- `toggleBookmark()` - Add/remove bookmark
- `saveProgress()` / `loadProgress()` - LocalStorage
- `toggleTheme()` - Light/Dark mode
- `parseMarkdown(text)` - Convert MD to HTML

**Event Listeners**: All user interactions

**Size**: ~500 lines

---

**Chapters**: 94 (from 9 markdown files)

**Generated by**: parse-course.js

---

### 5. parse-course.js (2 KB) - **BUILD SCRIPT**

**Purpose**: Parse markdown files → generate course-data.js

**Usage**:
```bash
node parse-course.js
```

**What it does**:
1. Reads all полный_курс_sql_часть*.md files
2. Extracts chapters by headers (## for titles, # for sections)
3. Converts to JSON format
4. Saves as course-data.js (1.2 MB)

**Run this if**:
- You modify markdown files
- course-data.js is missing
- You want to rebuild course data

**What it does**:

## 🔄 HOW IT WORKS | КАК ЭТО РАБОТАЕТ

### Build Phase | Фаза сборки

```
markdown files      →   parse-course.js   →   course-data.js
(9 parts)          (Node.js script)      (JSON, 1.2 MB)
```

### Runtime Phase | Фаза выполнения

```
index.html
    ↓
  style.css (load styles)
    ↓
  course-data.js (load chapters)
    ↓
  course.js (initialize app)
    ↓
  CourseApp class
    ├─ Load first chapter
    ├─ Setup event listeners
    ├─ Load progress from localStorage
    └─ Ready to interact!
```

### User Interaction | Взаимодействие пользователя

```
User clicks "Next"
    ↓
Event listener triggers
    ↓
course.js handles it
    ↓
Update UI (display new chapter)
    ↓
Save to localStorage
    ↓
Update statistics
```
