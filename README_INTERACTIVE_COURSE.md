Добро пожаловать в интерактивную версию "Полного курса SQL: От новичка до профессионала"!

## ✨ Возможности

### 🎯 Основной функционал
- **94 интерактивных главы** - полный курс разбит на удобные части
- **Отслеживание прогресса** - сохранение вашего прогресса в браузере (localStorage)
- **Маркировка завершенных глав** - отметьте главы как пройденные
- **Система закладок** - сохраняйте важные главы для быстрого доступа
- **Поиск по курсу** - легко найти нужную главу
- **Статистика учебы** - отслеживайте количество часов, серию дней обучения

### 🎨 Интерфейс
- **Темный/Светлый режим** - переключайте тему в любой момент
- **Адаптивный дизайн** - работает на всех устройствах
- **Красивая подсветка кода** - встроенная подсветка SQL-кода
- **Сертификат о завершении** - получите сертификат по окончанию курса

### ⌨️ Горячие клавиши
- **Alt + →** - Следующая глава
- **Alt + ←** - Предыдущая глава
- **Alt + M** - Отметить как пройденное
- **Alt + B** - Добавить в закладки

## 🚀 Быстрый старт

### Вариант 1: Открыть локально
1. Откройте файл `index.html` в браузере
2. Начните учиться!

### Вариант 2: Запустить простой сервер
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js
npx http-server

# PHP
php -S localhost:8000
```

Затем откройте http://localhost:8000 в браузере.

## 💾 Сохранение прогресса

Ваш прогресс автоматически сохраняется в `localStorage` браузера:
- Текущая глава
- Завершенные главы
- Закладки
- Имя студента
- Статистика учебы

**Данные не удаляются при перезагрузке страницы!**

⚠️ **Важно**: Данные теряются если:
- Очистить кэш браузера
- Использовать приватный режим (данные удаляются при закрытии)
- Удалить сайт из локального хранилища
