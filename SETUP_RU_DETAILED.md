## 📝 Пошаговые Инструкции

### Способ 1️⃣: Просто Открыть Файл (Самый Простой)

Это самый быстрый способ - никаких команд не требуется!

#### На Windows:
```
1. Откройте папку с файлами проекта
2. Найдите файл "index.html"
3. Дважды кликните на него
4. Браузер откроется с курсом
```

**Видеоинструкция:**
- Зайти в папку проекта
- Найти файл `index.html` (иконка браузера)
- Двойной клик по файлу
- ✅ Курс загружается!

#### На Mac:
```
1. Откройте Finder
2. Перейдите в папку проекта
3. Найдите файл "index.html"
4. Кликните правой кнопкой мыши
5. Выберите "Открыть с помощью" → ваш браузер (Chrome, Safari, Firefox)
6. ✅ Курс запустится!
```

#### На Linux:
```bash
# Откройте терминал в папке проекта и выполните:
xdg-open index.html

# Или двойной клик на index.html в файловом менеджере
```

### Способ 2️⃣: Python Сервер (Рекомендуется)

**Преимущества:**
- ✅ Более надежный способ
- ✅ Лучше имитирует реальную работу
- ✅ Python установлен на большинстве компьютеров

#### Проверка наличия Python:

**Windows:**
```bash
# Откройте Command Prompt (cmd.exe) и выполните:
python --version
# или
python3 --version
```

**Mac/Linux:**
```bash
# Откройте терминал и выполните:
python --version
# или
python3 --version
```

Если вы видите версию (например, `Python 3.9.7`) - отлично, Python установлен!

#### Если Python не установлен:

**Windows:**
1. Перейдите на https://www.python.org/downloads/
2. Нажмите "Download Python" (рекомендуется последняя версия 3.x)
3. Запустите установщик
4. **ВАЖНО:** Отметьте галочку "Add Python to PATH"
5. Нажмите "Install Now"
6. Перезагрузитесь

**Mac:**
```bash
# Установка через Homebrew (самый простой способ)
brew install python3

# Если Homebrew не установлен, сначала:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

**Linux:**
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3

# Fedora/CentOS
sudo yum install python3

# Arch
sudo pacman -S python
```

#### Запуск с Python:

1. **Откройте терминал (Command Prompt на Windows)**

**Windows:**
- Нажмите `Win + R`
- Введите `cmd`
- Нажмите Enter

**Mac/Linux:**
- Откройте приложение "Терминал" (Terminal)

2. **Перейдите в папку проекта**

```bash
# Windows (пример):
cd C:\Users\YourName\Downloads\project
# или через Проводник: правый клик → "Открыть в PowerShell"

# Mac/Linux (пример):
cd /Users/YourName/Downloads/project
# или если вы в одной папке:
cd project
```

**Быстрый способ на Windows:**
- Откройте папку проекта в Проводнике
- В адресной строке напишите: `cmd`
- Нажмите Enter
- Готово, вы в нужной папке!

3. **Запустите сервер**

```bash
# Python 3 (рекомендуется)
python -m http.server 8000

# Если первая команда не сработала, попробуйте:
python3 -m http.server 8000

# Или для Python 2 (старые версии):
python -m SimpleHTTPServer 8000
```

4. **Откройте браузер**

Если вы видите в консоли:
```
Serving HTTP on port 8000 ...
```

Это отлично! Теперь:
- Откройте браузер
- В адресной строке введите: `http://localhost:8000`
- Нажмите Enter
- ✅ Курс загружается!

5. **Остановка сервера**

Когда захотите остановить сервер:
- Нажмите `Ctrl + C` в терминале

## 🔍 Решение Проблем

### ❌ Проблема: "Не могу найти папку проекта"

**Решение:**
1. Убедитесь, что вы скачали/распаковали проект
2. Найдите файл `index.html` в своих файлах
3. Это и есть корневая папка проекта

### ❌ Проблема: Python не найден

**Решение:**
```bash
# Попробуйте:
python3 --version

# Если не работает, установите заново с добавлением в PATH:
# Windows: https://www.python.org/downloads/ (отметьте "Add to PATH")
```

### ❌ Проблема: "Port 8000 is already in use"

**Решение:**
Порт уже занят другой программой. Выберите другой:

```bash
# Python
python -m http.server 8001   # или 8002, 8003...

# Node.js
npx http-server -p 8001
```

Затем откройте: `http://localhost:8001`

### ❌ Проблема: Курс не загружается

**Проверьте:**
1. JavaScript включен в браузере (обычно включен по умолчанию)
2. Файл `course-data.js` присутствует в папке проекта
3. Попробуйте другой браузер
4. Очистите кэш браузера (Ctrl+Shift+Delete)

### ❌ Проблема: "Не видно курса, только белая страница"

**Решение:**
1. Откройте DevTools (F12 или Ctrl+Shift+I)
2. Перейдите на вкладку "Console"
3. Посмотрите есть ли ошибки (красные текст)
4. Если нужна помощь, сделайте скриншот

### ❌ Проблема: Мой прогресс исчез

**Решение:**
К сожалению, данные хранятся в браузере локально. Они могут исчезнуть если:
- Очистили историю/кэш браузера
- Удалили файлы cookie
- Используете приватное окно (Incognito)

**Профилактика:**
- Не очищайте кэш этого сайта
- Или используйте сертификат (скачайте в конце курса)
